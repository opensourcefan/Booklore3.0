8. Shelves — Custom Collections

Sidebar SHELVES section

Shelves are like playlists for your books. You can create as many as you want and assign any book to one or more shelves.

What You Can Do

ActionDescription
Create a shelfGive it a name and optionally a custom display icon or color
Add booksAssign books to a shelf from the book detail page or the cover's right-click menu
Remove booksTake books off a shelf without deleting them from your library
Rename a shelfChange its name at any time
Delete a shelfRemove the shelf catalog entry (the books inside are not deleted)
Browse a shelfClick a shelf in the sidebar to see only its books
Make a shelf publicAdmins can make shelves visible to all user accounts on the server
Kobo device shelfSpecial shelf type that automatically syncs to connected Kobo e-readers (see Section 19 for setup details)
Tip: Click Not Shelved (listed as Not Shelfed in the sidebar menu) to view all books that haven't been assigned to any custom shelf—perfect for sorting newly added files.

What You Can’t Do

  • Nest shelves inside other shelves (shelves are flat, not hierarchical)
Good to Know: Deleting a shelf does not delete the books inside it. The books remain in your libraries—only the custom shelf group is removed.

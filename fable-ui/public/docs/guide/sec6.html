6. Books — Adding, Browsing, and Managing

Sidebar All Books, or click any library

This section is the canonical workflow for a book’s lifecycle: create or import the record, review it in Staging, organize and maintain it, then clear its staged status when triage is finished.

Choose How to Add Books

RouteWhat happensUse it when
Topbar Upload → LibraryYou choose a library and one of its configured subpaths. Fable extracts available file metadata, applies the library naming pattern, and moves the upload directly into that library path. The library watcher then creates a staged book record.The destination is already known and no pre-import BookDrop review is needed.
Topbar Upload → BookDropThe browser sends the file to the current account’s BookDrop inbox: the global/shared inbox for an admin or a personal inbox for a non-admin. It remains pending until finalized.You want to review metadata, filenames, library, and subpath before library import. Continue in Section 7.
Host/library folder + Scan for New FilesYou copy files into a configured host or mounted library directory, then open that library’s menu and run Scan for New Files. Fable creates staged records for supported new files it discovers.You are importing files already available to the server, especially a batch.
Add Physical BookThe library menu creates a staged catalog placeholder with metadata but no readable digital file. An ISBN can be used to look up book information.You want to track one printed book.
Bulk ISBN ImportThe library menu looks up a list of ISBNs and creates staged physical-book records for successful entries while reporting skipped or failed entries.You want to catalog several printed books at once.
Good to Know: Upload is not another name for BookDrop. The same uploader dialog offers two destinations. Library bypasses BookDrop review and writes into the selected library path. BookDrop feeds the pending-file workflow described in Section 7.

Check Upload Limits and Destinations

Browser uploads default to a maximum of 100 MB per file. An administrator can raise the configured limit, up to the hard maximum of 1024 MB per file.

Plan Ahead: Before uploading, confirm the destination library allows the format and that the selected directory is writable. Fable applies the library naming pattern at import. If the resolved destination name already exists, the collision must be resolved rather than silently overwriting the existing file.

Staging Lifecycle: Staged, Review, Completed, Release

Sidebar HOME Staging

New digital imports and newly created physical-book records begin with staged=true. Staging is a triage flag, not a separate storage location: the book already belongs to its selected library. Use the tabs to decide what still needs attention.

Tab/actionMeaning and next step
StagedThe staged inbox: books that do not currently have a pending metadata proposal and are not classified as completed. Inspect the book, edit metadata, or start a metadata fetch. On desktop and tablet, an amber barcode badge means ISBN Discovery completed without finding a valid ISBN; a red warning badge means the ISBN check could not be completed. Hover either badge for the recorded reason and check time. Books without either badge have no recorded ISBN problem.
ReviewStaged books with fetched metadata proposals awaiting a decision. Open the metadata review, compare proposed and current values, then apply or reject as appropriate. Pending review wins over the other triage buckets while the book remains staged. Releasing a book removes it from all Staging triage tabs and counts; Release does not itself accept or reject the proposal.
CompletedStaged books whose metadata fetch has completed or whose ISBN has been verified, with no pending review proposal. Check the result before release.
ReleaseSelect one or more books and click Release. This changes only staged from true to false. It does not move files, alter metadata, change library or shelf membership, or delete anything.
Suggested loop: import → open Staged → correct or fetch metadata → resolve Review items → check Completed → select the books → Release.
Plan Ahead — Staging ISBN Work: ISBN providers have provider-specific request limits. Start with a small test batch, review the results before expanding the run, and reserve large batches for overnight processing. The Fable server must remain running until the batch finishes. Interrupted ISBN work does not resume automatically; restart it for the books that still need processing.

Browse Books

  • All Books — View every book in your collection, displayed as a grid of cover images
  • Filename Fallback — If a book has no metadata title yet, Fable displays the filename so the item remains recognizable in your list
  • Display Settings — Click the gear icon in the toolbar to adjust grid display preferences, such as cover text rows, category overlays, and how subtitles are shown (e.g., "Title : Subtitle")
  • Click any book cover to open its detail page with full description, author, series, formats, and rating details
  • Quick Back Navigation — The back arrow in Book Details returns you directly to your previous library, shelf, or search page
  • Right-click a book cover (or long-press on mobile) to access quick actions (such as reading, editing metadata, adding to shelves, or deleting)

Browse with the Directory Explorer

Book browser toolbar folder toggle button (left side of the header bar)

Fable includes a Directory Explorer — a collapsible folder-tree panel that slides out from the left side of the book browser. It lets you filter the current view by the actual folders on disk inside your libraries, exactly as they are organized in your filesystem.

Why Use the Directory Explorer?

If you already organize your collection into folders on disk — for example /Comics/Marvel/, /Books/Fiction/, or /Audiobooks/Sci-Fi/ — the Directory Explorer mirrors that structure directly in Fable. You can browse your library the same way you browse files on your computer, with zero metadata setup required. It is also a great complement to shelves and filters: use folders for broad organization and shelves for cross-cutting collections.

Opening and Closing

  • Open: Click the folder toggle button in the book browser toolbar (visible when viewing All Books or any library). The panel slides out from the left.
  • Close: Click the close icon in the panel header, or click the folder toggle again.
  • Resize: Drag the right edge of the panel to adjust its width. Your preferred width is remembered across sessions.
  • Collapse the left sidebar: If you need more horizontal room, collapse the main left sidebar first using the sidebar toggle button in the topbar to give both the folder tree and the book covers more space.

Navigating the Folder Tree

ActionIcon/ButtonWhat It Does

Tip: While a directory filter is active, the book list switches to filename order (instead of metadata title order) so the sort order matches what you see in your file manager. Clearing the folder filter restores your previous sort preference.
Good to Know: The Directory Explorer works alongside all other filters. You can select a folder and then use the right-side filter sidebar to narrow results further by reading status, media type, genre, or rating.

Manage Multiple Books

Select book-card checkboxes, then open the selection action panel. Actions appear only when your permissions, selection, storage type, and enabled features allow them.

  • Metadata: automatic or custom fetch, ISBN Discovery, bulk metadata editor, multi-book editor, restore titles from filenames, lock/unlock fields, and cover generation.
  • Organization: assign shelves, move between shelves while viewing a shelf, remove from a shelf or all shelves, assign media type, and add to a Story Arc.
  • Files: run the file mover on local storage, or open the file attacher to combine eligible single-file source books from one library into a target book.
  • AI Search: embed selected books, mark or unmark them for embedding, or delete selected embeddings when AI Search is enabled.
  • Reading and classification: update read status, age rating, content rating, or reset supported reading progress.
  • Deletion: permanently delete selected files when allowed, or remove selected records from the library while retaining files according to the chosen removal option.
  • Staging: on the Staging page, select one or more checked books and use Release only after review.
What is a metadata sidecar file?
A sidecar file is a small metadata file saved on disk beside a book or in the designated physical-book location. It can preserve details such as title, author, description, and ratings for later import or rebuilding. Physical-book creation writes a sidecar for the placeholder.
Physical Shelf View: The Physical Books page draws a custom shelf rail under each visual row, creating a virtual bookshelf display that wraps correctly as your collection grows.

Know the Book Management Limits

  • Directly edit the book file contents (Fable is a reader and organizer, not an editor)
  • Move or rename folders from the directory explorer (it is a filtering tool, not a file manager)
Be Careful:
  • Deleting a book with “delete from disk” enabled is permanent. The file is gone. There is no recycle bin.
  • Removing from Library vs. Deleting from Disk: Removing a record keeps its files. The removal submenu distinguishes removal until a future scan from permanent catalog suppression. Deleting from disk removes the real file.
  • Bulk deleting books is powerful — double-check your selection before confirming.
  • Deleting the last file: If you delete the only readable file from a digital book record, Fable removes the empty catalog card. To keep a catalog entry without a file, create a Physical Book entry instead.

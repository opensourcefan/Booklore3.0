14. Story Arcs — Guided Reading Paths

Sidebar STORY ARCS section

Story Arcs let you create guided reading paths through your collection. Instead of reading books in publication order or series order alone, you can arrange comics, graphic novels, and books into a custom chapter-by-chapter sequence that follows a specific storyline or crossover event.

What Are Story Arcs?

A Story Arc is a curated reading order made up of chapters (rows) containing books (cards). Each chapter can represent a phase of the story, a collected edition, or a thematic grouping. Books within a chapter flow left-to-right, and chapters flow top-to-bottom with visual down-arrow connectors showing the reading path.

Story Arcs are ideal for:

  • Comic book crossover events — Arrange issues from multiple series into the correct reading order
  • Shared universe reading orders — Follow a character or team across different titles
  • Curated book lists — Create a guided journey through a genre, author, or theme
  • Trade paperback contents — Document exactly which issues are collected in each volume

Browsing Story Arcs

Sidebar Story Arcs

Story Arcs have their own sidebar section (separate from HOME). Expand it to jump straight to an individual arc; each arc shows a book-count badge. Click the section header to open the Story Arcs browser grid.

The browser shows all your arcs as cards. Each card displays the arc name, the number of books it contains, your reading progress (how many books you have marked as read), and a cover thumbnail. By default the cover comes from the first book; you can pick a specific cover book while editing (see below). Use the search bar at the top to filter arcs by name.

Viewing a Story Arc

Click any arc card (or a sidebar arc link) to open its Reading Path view. This is the main workspace where you see all chapters and their books laid out in reading order.

Reading Path Layout

  • Chapters appear as labeled rows stacked vertically, connected by gradient down-arrow connectors
  • Books appear as cover cards within each chapter, flowing left to right
  • Core issues (solid border) are the main storyline; tie-in issues (dashed border, desaturated) are supplementary
  • The NEXT UP badge highlights the first unread book in the arc, with a glowing purple border
  • Click any book cover to open its detail page; hover for Details and Read buttons

About This Arc Panel

At the top of the reading path, a collapsible panel can show:

  • A summary description of the story arc
  • An external guide link — a URL to the original reading order source (e.g., ComicBookReadingOrders.com)

Click the Guide button to open the external link in a new tab. The panel starts collapsed by default; click the header bar to expand or collapse it.

Creating a Story Arc

There are two ways to create a new Story Arc:

Method 1: From the Story Arcs Page

  1. Go to Story Arcs from the sidebar
  2. Click the + New Story Arc button in the header
  3. Enter a name for the arc and click Create
  4. The new empty arc opens immediately in edit mode

Method 2: From the Book Browser

  1. Select one or more books in the book browser using the grid checkboxes
  2. Click the Assign to Story Arc button in the selection toolbar
  3. In the dialog, choose an existing arc or type a new arc name
  4. Optionally select a target chapter or create a new one
  5. Enable Auto-group by Series to automatically sort books into separate chapters by their series metadata
  6. Click Apply to add the books

Editing a Story Arc

Click the Edit Layout button on any arc page to enter edit mode. In edit mode you can:

ActionHow
Rename a chapterType directly into the chapter title input field
Add a new chapterClick Add Chapter in the header, or use Add Chapter Above / Add Chapter Below on a chapter row
Remove a chapterClick the X button on the chapter header (books merge into the previous chapter)
Reorder chaptersDrag the chapter by its handle, or use the up/down arrow buttons. On phones, chapter dragging is limited in Card View so the page can scroll; use Chapter Sort mode or the arrow buttons instead
Add books to a chapterClick the + button on the chapter header to open the book picker dialog
Remove a bookHover over a book cover and click the red X
Toggle core/tie-inClick the star button on a book cover to switch between core issue and tie-in
Set arc coverIn edit mode, click the image button on a book card to Set as Cover Image for the arc browser card; clear it to fall back to the first book
Move a bookClick the crosshair button to pick up a book, then click Move Here on any target card or chapter
Auto-organize by seriesClick Auto-Organize by Series to group books in the first chapter into separate chapters by their series metadata, sorted by issue number

Drag and Drop

  • Within a chapter: Drag book cards left or right to reorder them (on phones, drag from the cover handle in edit mode so the page can still scroll)
  • Between chapters: Drag a book card from one chapter row into another
  • Chapter reordering: Drag an entire chapter by its handle to change the chapter order (or use Chapter Sort mode)

Chapter Sort Mode

Click the Chapter Sort button in the header to switch to a compact vertical list view. This mode hides the book cards and shows only chapter names with book counts, making it easy to reorder chapters by dragging or using the up/down arrow buttons. Click Card View to return to the full layout.

External Guide & Summary

In edit mode, a panel appears below the header where you can:

  • Paste an external URL to a reading order guide (e.g., from ComicBookReadingOrders.com)
  • Write or paste a summary description of the story arc
  • Click Remove Overview to clear both the URL and description

Fable can also attempt to scrape the title and description from supported guide websites when you paste a URL.

Reading Progress

  • Each book card shows its read status with a colored indicator in the bottom-left corner
  • Click the indicator to open a menu where you can change the read status (Unread, Reading, Read)
  • A progress bar appears on books you have started but not finished
  • The NEXT UP badge automatically points to the first unread book in the arc
  • The Story Arcs browser page shows your overall completion percentage for each arc

Deleting a Story Arc

Click the red trash icon in the header of any arc page. You will be asked to confirm. Deleting an arc removes the reading path and all chapter organization, but does not delete the books themselves from your library.

Tip: Story Arcs are independent of shelves and series. A book can appear in multiple arcs, on multiple shelves, and in its regular series all at the same time. Use arcs for reading order guidance and shelves for general collection organization.
Good to Know: Empty chapters are preserved when you save, so you can leave placeholder chapter rows for a reading order you are still filling in. Removing all books from a Story Arc does not delete the arc itself—the arc name, external guide link, and summary description are preserved so you can rebuild the reading path later.

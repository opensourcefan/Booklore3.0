29. Glossary

TermDefinition
AIP — AI Panel DetectionAI feature that identifies individual comic panels on a page; when a comic has panel data, an AIP badge appears on the book card
AIS — AI SearchAI-powered natural language search that lets you find books by themes, characters, concepts, or ask questions about a book’s contents; embedded books show an AIS badge on the book card
AnnotationA highlight, underline, or note you create while reading
App Settings backupA JSON transfer of application-wide configuration from Backups. It excludes email records, redacts clientSecret/apiKey/cookie, and is not a database, secret, media, progress, or annotation backup
Audit LogAn admin-only view of explicitly recorded event rows; it is an operational aid with the coverage and forensic limitations in Section 27, not a record of every request or state change
AudiobookAn audio book format; Fable supports folder-based audiobooks containing MP3, M4A, M4B, or OPUS files
AZW3Amazon Kindle e-book format (KF8)
BookDropA permission-gated shared or personal pre-import inbox where files are inspected, corrected, and finalized into an assigned library; see BookDrop Imports
Browser accessUsing Fable directly in a web browser; this uses Fable’s web reader and is distinct from OPDS downloads, emailed files, or native e-reader synchronization
BookmarkA saved position marker in a book
CB7Comic book archive format using 7-Zip compression
CBXFable’s unified comic reader that opens CBZ, CBR, and CB7 files with panel detection, multiple scroll modes, and a magnifier
CBZ / CBRComic book archive formats (CBZ = ZIP, CBR = RAR) containing image files
Coordinated backupA recovery set whose database, app data, media, and configuration were captured from the same controlled write window; see Routine Backup Procedure
CronA six-field scheduling expression (second minute hour day-of-month month day-of-week) evaluated in the Fable server/JVM timezone; see Background Tasks
Completed (Staging tab)Books in Staging whose metadata has already been fetched or applied and which do not have a fetched proposal currently taking priority in Review
Database preflightThe admin-only Backups checklist that evaluates entered paths, a minimum entered value of 15 GB free space, and operator confirmations before enabling Copy Restore Command; it does not inspect the host, prove that 15 GB is sufficient, or run a restore
Database logical dumpA SQL representation of database schema/data created by an external database command. Fable only prepares/copies the helper command; the dump does not include library media or app-data files
Device syncA configured Kobo or KOReader integration that exchanges supported shelf/progress data; it is not the same as opening Fable in a browser
EPUBThe most common e-book file format
FB2FictionBook 2 — an XML-based e-book format popular in Russian-language publishing
FETCHEDThe metadata-proposal status meaning a candidate has been fetched and is awaiting review; it is not proof that the candidate was applied
Forward AuthFable’s environment-configured remote-auth login path, where a trusted reverse proxy authenticates the user, strips spoofable client identity headers, and supplies verified headers. It has no Settings UI; see Authentication
ISBN DiscoveryA task that scans front matter and, when needed, back pages for checksum-valid ISBNs, verifies candidates, and uses a verified ISBN to fetch metadata; ambiguous or review-required results become metadata proposals
JWTJSON Web Token — the authentication token used for login sessions
KEPUBKobo’s enhanced EPUB format
LibraryA connection between Fable and a folder on your server where book files are stored
Off-host backupAn encrypted recovery copy stored outside the Fable host/failure domain, with access controls and recoverable keys; a second folder on the same disk is not off-host protection
Personal libraryAn optional private library created under /books/_users/{id}/ for a Settings-created non-admin when Create personal library is enabled. OIDC/Forward Auth provisioning does not create it automatically; /books/_users must be writable
LLM ProfileA saved configuration of AI model settings (provider, model, API key, tuning parameters) that can be switched with one click
M4A / M4BAAC-based audio formats; M4B is the audiobook variant with chapter markers and bookmarking support
Magic ShelfAn automatically populated collection based on filter rules
Media TypeA category for your books (e-book, PDF, comic, audiobook, or custom); physical placeholders remain a separate dedicated browsing path under Physical Books
MetadataInformation about a book — title, author, description, cover, ISBN, etc.
Metadata ProposalA fetched metadata candidate attached to a background task for a specific book; while its status is FETCHED it appears in Staging’s Review workflow for an authorized user to inspect
MOBIOlder Amazon Kindle e-book format (predecessor to AZW3)
MP3The most common compressed audio format; widely used for audiobooks
OPUSAn open, royalty-free compressed audio format supported for folder-based audiobooks
OIDCOpenID Connect — a single sign-on standard for logging in via a third-party provider
OPDSA standard protocol that lets e-readers browse and download from your library
PDFPortable Document Format — standard document files (books, manuals, magazines)
PHY — PhysicalA catalog entry for a physical book you own; no digital file is required, and the PHY badge appears on the book card
RAGRetrieval-Augmented Generation — a technique that retrieves relevant text chunks before generating AI responses, improving accuracy
Reconcile LibraryA full comparison of a library’s catalog records against disk that can remove missing-file entries and purge disallowed formats; use Scan for New Files for additive discovery
Recovery setThe coordinated collection needed to rebuild Fable: logical database dump, matching library media, app data, deployment/path notes, application settings, and a separately protected secret inventory; see Backup and Restore
Restore testA recovery rehearsal in an isolated non-production environment that proves the backup can restore and passes representative login, permission, catalog, reader, progress, and integration checks
ReleaseThe Staging action that clears selected books’ staged status and removes them from the staging queue; it does not move files, alter metadata, or control All Books visibility
Review (Staging tab)The Staging triage view for books with FETCHED metadata proposals awaiting an authorized metadata decision; Review takes priority over Staged or Completed classification
Reverse ProxyA server that sits between the internet and Fable, handling security and routing
Semantic ChunkingAn intelligent text-splitting method that respects natural boundaries (paragraphs, sections) rather than cutting at fixed character counts
Role presetA starting permission pack when creating a user: Reader, Contributor, Librarian, or Admin (Custom means mixed checkboxes)
ShelfA user-created collection for grouping books (like a playlist)
SidecarA metadata file written beside a digital book as <base-name>.metadata.json, or in a library directory for a fileless physical book. Manual per-library sidecar backup is under Backups → Sidecar; it is not a central archive, database backup, media backup, reading-progress backup, or annotation backup
Show libraryAdmin toggle: when on, a user’s personal library appears under the sidebar USERS section for the admin; when off (default), it stays out of the admin catalog
SMTPSimple Mail Transfer Protocol — the standard for sending email
Story ArcA curated, chapter-based reading path through books you can access (ideal for comic crossovers and shared-universe orders); lists only include books from your visible libraries
Staged (Staging tab)The staging inbox view for books that have not been classified into Review by a fetched metadata proposal or into Completed by fetched/applied metadata
StagingThe sidebar workspace for triaging imported books through Staged, Review, and Completed views before clearing their staged status with Release; it is a workflow flag, not a separate storage location
Task ManagerThe permission-gated Settings → Tasks page for manual runs, supported schedules, recent history, cooperative cancellation, and error-notification settings; interrupted tasks are cancelled on restart rather than resumed
Tasks / Notifications bellTopbar status center: the Tasks tab shows live running work; the Notifications tab is a durable WARN/ERROR failure inbox you can dismiss

BookCard Mobile Cover Popup: Root Cause and Fix

Date: 2026-04-18 | Scope: Shared BookCard mobile popup controls (status button and 3-dot menu)

Root Cause Proven Fix Implemented Release Pending in this report snapshot

User Symptom

  • Inside the mobile cover popup, tapping the left status button or right 3-dot menu appears to do nothing.
  • This occurs even though the click handlers are wired and testable in unit tests.

Timeline Checked (Recent Pushes)

  • v3.10.35: Fix mobile popup buttons and cover quality
  • v3.10.36: Fix mobile viewer controls and cover alignment
  • v3.10.37: Fix stale book card popup overlays

Evidence from Feature Code

  • Mobile popup backdrop uses z-index 1200 in book-card.component.scss.
  • Popup menus in the mobile viewer template were appendTo="body" with no baseZIndex override.
book-card.component.scss .book-card-mobile-preview-backdrop { z-index: 1200; }
book-card.component.html (before fix) <p-tieredmenu #mobileReadStatusMenu ... appendTo="body"></p-tieredmenu> <p-tieredmenu #mobileMenu ... appendTo="body"></p-tieredmenu>

Evidence from Underlying Framework (PrimeNG TieredMenu)

  • TieredMenu calculates overlay z-index using baseZIndex + config.zIndex.menu.
  • TieredMenu defaults: baseZIndex = 0, autoZIndex = true.
  • PrimeNG default config: zIndex.menu = 1000.
primeng-tieredmenu.mjs moveOnTop() { if (this.autoZIndex) { ZIndexUtils.set('menu', this.container, this.baseZIndex + this.config.zIndex.menu); } } Defaults: autoZIndex = true baseZIndex = 0
primeng-config.mjs default zIndex values modal: 1100 overlay: 1000 menu: 1000 tooltip: 1100

Actual Root Cause

In mobile popup mode, TieredMenu overlays were opening behind the popup backdrop layer. The backdrop was fixed at z-index 1200, while TieredMenu defaulted to menu z-index around 1000. Therefore, button taps did execute handlers, but overlays rendered under the dark backdrop and appeared non-functional.

LayerSourceEffective z-indexOutcome
Mobile popup backdropFeature SCSS1200Above app content
TieredMenu overlay (before fix)PrimeNG defaults0 + 1000 = 1000Behind backdrop

Fix Implemented

  • Added a dedicated mobile popup menu base z-index in BookCard component: inlineMobileMenuBaseZIndex = 1500.
  • Bound both popup-mode menus to this base value via [baseZIndex]="inlineMobileMenuBaseZIndex".
  • Left non-popup card menus unchanged.
book-card.component.ts readonly inlineMobileMenuBaseZIndex = 1500;
book-card.component.html (after fix) <p-tieredmenu #mobileReadStatusMenu ... [baseZIndex]="inlineMobileMenuBaseZIndex" appendTo="body" ...></p-tieredmenu> <p-tieredmenu #mobileMenu ... [baseZIndex]="inlineMobileMenuBaseZIndex" appendTo="body" ...></p-tieredmenu>

Regression Coverage Added

  • Template-level regression assertion ensures popup-mode menus retain explicit base z-index binding.
  • Component-level assertion ensures base z-index remains above the popup backdrop threshold.

1. What Is BookLore?

BookLore is a self-hosted digital library — a personal application you run on your own computer or server to organize, read, and manage your book and comic collection. Think of it as your own private digital bookshelf accessible from any web browser on any device.

Supported Formats

FormatDescription
PDFStandard document files (books, manuals, magazines)
EPUBCommon e-book format used by most e-readers
CBZ / CBRComic book archives (zipped or RAR-compressed image collections)
AudiobooksAudio files organized in folders (MP3, M4A, etc.)
Physical BooksCatalog entries for physical books you own (no digital file required)

What You Can Do

  • Store and organize thousands of books across multiple libraries
  • Read books, comics, and listen to audiobooks directly in your browser
  • Track your reading progress across devices
  • Highlight text, add bookmarks, and write notes
  • Search and filter your entire collection
  • Fetch book information (metadata) from the internet automatically
  • Share your catalog with e-readers via OPDS feeds
  • Manage multiple users with different access levels
  • Use AI to detect comic panels for panel-by-panel reading

2. Getting Started — First-Time Setup

When you open BookLore for the very first time, you will see the Setup Wizard.

What You Do

  1. Create your admin account — Choose a username and strong password. This is the main administrator account.
  2. Set up your first library — Point BookLore to the folder on disk where your books are stored (for example, /books).
  3. Configure authentication — Choose how users will log in (local password, OIDC, or forward auth).

What You Can’t Do

  • You cannot skip creating the admin account — it is required.
  • You cannot change the admin username later through the normal interface.
  • You cannot undo the first-time setup once completed — but you can change all settings afterward.
Be Careful: Choose a strong password. Anyone who knows this password has full control over BookLore. If you lose the admin password and have no other login method configured, recovery requires direct database access.

3. The Dashboard — Your Home Screen

The Dashboard is the first screen you see after logging in. It provides a quick overview of your library.

What You Can Do

  • See library statistics at a glance (total books, reading status, etc.)
  • Access recently added books
  • Configure dashboard sections from Dashboard Settings, including adding up to 20 scrolling panels for libraries, shelves, series, authors, or other supported dashboard content
  • Refresh the page on mobile without the dashboard cards stretching into tall broken columns; the dashboard now recalculates its grid width after the page finishes loading
  • Jump to any section using the sidebar navigation

What You Can’t Do

  • Place dashboard panels at arbitrary pixel positions outside the grid system

5. Libraries — Organizing Your Collection

A Library is a connection between BookLore and a folder on your computer or server where book files are stored.

What You Can Do

  • Create multiple libraries — For example, one for “Fiction,” one for “Comics,” one for “Audiobooks”
  • Scan for new files — Tell BookLore to look for files that are not already known in a library
  • Reconcile libraries — Force BookLore to compare a library against disk and update library records to match
  • Open Library Maintenance — Run high-impact library-wide actions from a dedicated maintenance dialog instead of mixing them with routine work
  • Open Library Settings and Manage Directories separately — Routine library settings now live in Library Settings, while library path changes live in Manage Directories
  • See which directories are already imported while managing directories — The Manage Directories list marks directories already in the library so you can tell imported paths from new additions at a glance
  • Choose whether new directories should scan immediately — Save updates directory membership only, while Save & Scan New Directories imports only from the newly added paths
  • Save library changes without an automatic reconcile — Editing settings or adding directories no longer silently triggers a full reconcile afterward
  • Move between library settings, directories, and maintenance from inside the dialogs — The library-management dialogs now link to one another so you can stay in one workflow instead of backing out to the menu each time
  • Use a dedicated safe path before reconcile — The maintenance dialog now points routine discovery work back to Scan for New Files and requires an explicit acknowledgement before Reconcile Library can run
  • Use a roomier mobile directory picker — On phones and other compact screens, the directory picker now fits the dialog width correctly without slight sideways overflow, keeps search and selection controls in compact rows, and leaves more vertical space for the actual folder list
  • Use the mobile sidebar grab handles — The left and right sidebar width bars now stay visibly available on touch devices as always-on touch handles so you can see where to grab, drag horizontally to resize, and drag vertically to help scroll long side panels
  • Use the phone back gesture to close the active mobile panel or popup first — On mobile, the first back gesture now dismisses the topmost open surface (for example filter sidebars, topbar popovers, book preview viewers, and reader overlays) before BookLore navigates away underneath it
  • See preparation feedback for large imports — When creating a library with many files, the dialog now shows an in-between working state before the full progress overlay appears
  • Check library health — Verify the folder is accessible and working
  • Delete libraries — Remove a library from BookLore without deleting the original source files on disk
  • Restrict library access — Control which users can see which libraries
Good to Know: The normal library menu keeps Library Settings, Manage Directories, and Library Maintenance grouped together near the bottom, above Delete Library, and the dialogs now cross-link to one another so you can move between them without reopening the menu. Use Library Settings for naming, icon, and scan behavior. Use Manage Directories when you intentionally want to add or remove library paths. Inside Manage Directories, Save updates paths only, while Save & Scan New Directories imports only from newly added directories. Scan for New Files remains the library-wide safe additive discovery action, while Reconcile Library and library-wide sidecar import/export/backup tools stay inside Library Maintenance, where reconcile now requires an explicit acknowledgement before it can run. Scheduled library scans now follow that same additive new-file-only behavior. Changing directory-tag rules no longer silently retags existing books during a settings save, and additive scans only queue follow-up directory tagging for the books they just imported.

What You Can’t Do

  • Assign the same folder to two different libraries (each folder should belong to one library)
  • Manage files on remote cloud services directly — BookLore reads from local or network-mounted folders
Be Careful:
  • Deleting a library removes the catalog entry, not the source files on disk. If you want to delete real book files, that happens through book-file deletion flows, not library removal.
  • Moving or renaming book files outside of BookLore will cause them to appear missing. Always let BookLore manage file movements.
  • Use Reconcile Library intentionally. It is not the same as a safe new-file scan and may change existing library records to match disk.
  • If your book folder is on a network drive, set DISK_TYPE=NETWORK in your environment configuration for better compatibility. Automatic metadata writes stay disabled there, but you can still run manual sidecar backups when you want a portable metadata snapshot.

6. Books — Adding, Browsing, and Managing

Browsing Books

  • All Books — View every book in your collection, displayed as a grid of cover images
  • Untitled cards fall back to the filename — If a book has no stored metadata title yet, BookLore shows the asset filename on the card so the item remains identifiable
  • Adjust browser display settings from the cog menu — Use the display-settings popover to change cover text rows, overlays, and whether subtitles appear after the main title as Title : Subtitle; that subtitle format now stays consistent across the main grid, table titles, cover-tooltips, and the cover preview panel once the browser list loads metadata subtitles from the API
  • Library switching can feel faster after the first hover — When you pause on a library in the sidebar, BookLore quietly warms a small set of that library’s thumbnails so the next switch shows fewer blank covers while images stream in
  • Click any book cover to open its detail page with full information
  • Close book details cleanly — The back arrow in Book Details returns you to the page you opened from instead of walking backward through every detail view
  • Right-click a book cover (or long-press on mobile) for quick actions

What You Can’t Do

  • Directly edit the book file contents (BookLore is a reader and organizer, not an editor)
  • Upload books from this screen (use BookDrop for that — see Section 7)
  • Move or rename folders from the directory panel (it is a browser/filtering tool, not a file manager)
Be Careful:
  • Deleting a book with “delete from disk” enabled is permanent. The file is gone. There is no recycle bin.
  • When Allow File Deletion is turned off, BookLore hides the “Delete from Disk” choice. You can still use Remove from Library to hide the catalog entry while leaving the file on disk, and routine scans/watchers should not bring that removed book back on their own.
  • Bulk deleting books is powerful — double-check your selection before confirming.
  • If you delete the only readable format from a normal digital book, BookLore now removes that empty catalog shell instead of leaving behind a metadata-only entry. If you want a deliberate metadata-only placeholder, create a Physical Book instead.

7. BookDrop — Importing New Books

BookDrop is a watch folder — a special folder where you drop new book files, and BookLore will detect and import them.

How It Works

  1. Place files in the BookDrop folder (usually mapped to ./bookdrop in Docker)
  2. BookLore detects the new files automatically (or you can click “Rescan”)
  3. Go to the BookDrop page in BookLore to see pending files
  4. Review and edit — Adjust metadata, assign to a library, set the destination path
  5. Finalize — Click to import the files into your library

What You Can Do

ActionDescription
RescanManually trigger a scan of the BookDrop folder
Preview filesSee file details before importing
Edit metadataChange title, author, cover, etc. before import
Bulk editUpdate metadata for multiple files at once
Pattern extractionAutomatically parse filenames to extract title, author, series, etc.
Choose destinationPick which library and folder path to import into
Discard filesSkip files you don’t want to import
Finalize importMove files from BookDrop into your library
Watch follow-up directory taggingIf the destination library uses directory-based tags, a separate background task continues after import and shows live progress plus time remaining in the top bar and Task Management

What You Can’t Do

  • Import files directly from a URL or the internet — you must first download them to the BookDrop folder
  • Import unsupported file formats (stick to PDF, EPUB, CBZ, CBR, and audio formats)
Be Careful:
  • Files are moved, not copied, during import. After finalization, the original file in BookDrop is removed.
  • Pattern extraction is only as good as your filename. If filenames are messy, you may need to edit metadata manually.
  • Don’t put files into BookDrop while a scan is actively running. Wait for the scan to complete first, then add files and rescan.
  • Import complete may not mean directory tags are finished. When directory tagging is enabled, BookLore now treats tagging as a separate background phase, so wait for the Directory Tags task to finish before assuming all folder-based tags are in place.

9. Magic Shelves — Smart Filtered Collections

Magic Shelves are automatic collections that populate themselves based on rules you define. They update automatically as your library changes.

Examples

  • “Books I Haven’t Read Yet” (filter: reading status = Not Started)
  • “5-Star Books” (filter: rating = 5)
  • “All Comics” (filter: media type = Comic)
  • “Books by Stephen King” (filter: author = Stephen King)
  • “Added This Month” (filter: date added = last 30 days)

What You Can Do

  • Create magic shelves with custom filter rules
  • Combine multiple filters (e.g., “Unread comics rated 4+ stars”)
  • Edit filter rules anytime — the shelf updates automatically
  • Make them public (admin only) — share with all users
  • Delete magic shelves when no longer needed

What You Can’t Do

  • Manually add or remove specific books from a magic shelf — membership is determined entirely by the filter rules
Be Careful: A magic shelf with very broad rules may include thousands of books, which can slow down loading.

11. Bookmarks, Annotations, and the Notebook

Bookmarks

Simple position markers with an optional label. Use them to mark pages you want to return to.

  • Create: While reading, click the bookmark icon at your current position
  • Label: Give bookmarks descriptive names (e.g., “Important chapter”)
  • Color coding: Assign colors to categorize bookmarks
  • Navigate: Click any bookmark to jump back to that spot
  • Delete: Remove bookmarks when no longer needed

Annotations (Highlights and Notes)

Available in PDF and EPUB readers.

  • Highlight: Select text → choose a highlight color
  • Underline / Strikethrough: Additional marking styles
  • Add notes: Attach written notes to any highlight
  • Edit: Change colors, styles, or note text anytime
  • Delete: Remove individual annotations

The Notebook

A centralized view of all your annotations across every book.

  • See all highlights and notes in one place
  • Filter by book, type, or date
  • Search through your annotations
  • Export all annotations for backup
  • Quickly jump to the source book and location
Good to Know: Annotations are created while reading — you cannot create them from the Notebook view.

Metadata Review Queue

  • Use the bottom-right < and << buttons to copy missing fields or copy all fetched fields into the editable column
  • Use Skip to move the current proposal to the end of the current review queue and jump straight to the next proposal

Editing Metadata Manually

  • Edit title, author, description, and all other fields by hand
  • Upload a custom cover image
  • Add or change genres, categories, and moods
  • Set or update ISBN, publication date, and language
  • Restore an empty title from the primary filename with a dedicated metadata-editor button

  • Fetched cover images may not match your edition. Review the cover before applying.
  • ISBN lookup is the most reliable way to get accurate metadata. Use it when available.
  • You cannot undo a metadata overwrite once applied.

15. Metadata Manager — Bulk Editing

The Metadata Manager lets you edit metadata for many books at once.

What You Can Do

  • Select multiple books for batch metadata operations
  • Apply the same genre, category, or mood to many books at once
  • Bulk-update reading status or media type
  • Bulk-fetch metadata for selected books, with better recovery when a provider’s first match fails but later candidates still contain usable metadata
  • Limit a custom metadata fetch to all selected books, only books that have never been fetched, or only books whose last successful metadata fetch is older than a chosen age window
  • Restore titles for selected books from each book’s own primary filename from the bulk metadata actions menu when those books still have blank, unlocked titles
  • Delete all metadata for selected books from the bulk selection action bar
Be Careful: Bulk edits are immediate and cannot be reversed. Double-check your selection and changes before applying. Start with small batches to verify results. Bulk metadata deletion clears the selected books’ metadata in one step, but BookLore now keeps a filename-derived title when one is available so you can search again immediately.
Good to Know: If one metadata source fails to return a usable first match during a bulk custom scan, BookLore now falls back more gracefully instead of abandoning that whole book as aggressively. For providers that temporarily throttle large jobs, BookLore now retries the throttled request itself after the cooldown window, keeps the metadata task visible as still running, restores the metadata-fetch topbar pill from the active task state after refreshes or reconnects, lets you start a new custom fetch against only books that have never been fetched or books whose last successful metadata fetch is older than a selected age window, marks zombie in-progress metadata tasks as resumable instead of leaving them hung forever after a stop or restart, offers resume actions for stopped metadata batches, shows a clearly paused topbar state with the reset ETA instead of a stale time-left snapshot, opens a simple fetched-versus-remaining asset log when you click the topbar metadata pill, lets metadata editors cancel those metadata jobs directly from the progress widget even without broader task-manager access, interrupts long ComicVine cooldown waits promptly when you cancel the job, shows a clear cancellation-requested state instead of falsely marking a task fully cancelled before it actually stops, removes stale finished metadata tasks that the backend no longer reports, avoids holding the database transaction open during long provider cooldown waits, and uses a lighter top-match lookup path for ComicVine batch scans so large runs are less likely to exhaust the hourly request budget mid-batch.
Custom Metadata Fetch Defaults: The advanced custom metadata fetch dialog now opens with Merge Genres off by default and Manual Review on by default, so a new batch starts in a safer review-first mode unless you intentionally change those toggles.

  • Keep the desktop filter panel anchored flush to the right edge of its sidebar while you scroll and expand filter groups
  • Switch between libraries and shelves, including cached views reopened from the left sidebar, without manually refreshing or toggling the filter sort to repopulate metadata-backed sidebar filters such as authors, tags, series, publishers, and languages
  • Apply tag and other metadata edits without needing repeated browser refreshes before the right sidebar selections and facet counts catch up
  • Use the Date Added and Folder sidebar filters to narrow or exclude books by when they were imported or which directory they reside in, under every filter mode (AND, OR, NOT, 1)
  • Keep your filter sidebar visibility, filter sort mode, and expanded filter groups with your user account instead of one browser profile
  • Clear all filters with one click
Good to Know: In AND mode, the tag and sidebar option lists now narrow themselves to combinations that can actually exist together. After you choose one tag, BookLore only offers additional tags that still leave at least one matching book in the current result set.
Mode Changes Reset Sidebar Selections: Switching between AND, OR, NOT, and 1 now clears the current sidebar filter selections first. This prevents an old selection set from being silently reinterpreted under a different mode.
Mode Changes Now Re-sync the Whole Browser: The filter-mode button is no longer allowed to get ahead of the actual book-list filtering logic. BookLore now clears the previous sidebar state first, then activates the new mode from one shared parent state so the button, sidebar facets, and filtered book list stay in sync without repeated browser refreshes.
What Changed: After you already have sidebar selections active, switching to a different filter mode now updates the highlighted mode button immediately on the first click instead of waiting for a second click to make the new mode look selected.

Duplicate Review

BookLore’s duplicate finder is now designed as a scoped review tool. Open it from a library menu, then choose whether to scan your current filtered view, the current library, or all libraries.

Sidecar Backup Coverage: Manual per-library sidecar backup now follows each book’s real readable file even when a book also has non-book attachments, so EPUB, PDF, CBR, and CBZ titles are backed up alongside physical placeholders instead of only the physical entries appearing.

Good to Know: The duplicate review screen is intentionally non-destructive. It shows likely duplicate groups, highlights a suggested book to keep, lets you inspect another candidate side-by-side, and can open book details or launch a reader for digital files without deleting or merging anything.

22. Authentication — Login Methods

BookLore supports three ways to log in:

Local Password

The default method — log in with your username and password. Simplest option for personal use. Passwords are stored securely (hashed). Sessions use JWT tokens that auto-refresh.

OIDC (OpenID Connect)

Use a third-party identity provider (like PocketID, Keycloak, or Authentik) for single sign-on.

  1. Configure the OIDC provider (create a client for BookLore)
  2. In BookLore Settings → Authentication, enter the Client ID, Issuer URI, and JWKS URL
  3. Enable OIDC
  4. Users can now log in with the “Login with [Provider]” button

Forward Auth (Reverse Proxy)

If you run BookLore behind a reverse proxy with an authentication layer (like Authelia), BookLore can trust the proxy’s authentication headers.

Be Careful:
  • If using Forward Auth, NEVER expose BookLore directly to the internet. Always route through your authenticated reverse proxy.
  • OIDC requires correct URL configuration. Incorrect Issuer URI or JWKS URL will prevent login entirely.
  • Test new authentication settings before disabling local login, or you may lock yourself out.

25. Backup and Restore

Protecting your BookLore data requires backing up two things:

1. Application Settings (Database)

Quick Export (Settings Only)

  1. Go to Settings → Global Preferences → Settings Transfer
  2. Click Export
  3. Save the downloaded JSON file

This exports libraries, users, shelves, metadata settings, and preferences.

Full Database Backup (Recommended)

For complete protection (including all book metadata, reading progress, annotations, and shelf assignments), use a database dump:

docker exec mariadb mariadb-dump \
  --single-transaction --quick --no-tablespaces \
  -u root -p"YOUR_ROOT_PASSWORD" \
  booklore > booklore_backup.sql

Be Careful:
  • Settings export does NOT include reading progress, annotations, or book files. For full protection, do a database dump AND file backup.
  • Store backups in a separate location from your BookLore server.
  • Test your backups periodically. A backup you’ve never tested is a backup you can’t trust.
  • The Settings → Backups → Sidecar view now keeps a recent run history for the selected library. You can review up to the last 10 manual sidecar backup runs there, including attempted, exported, failed, and the user who triggered the run, instead of only seeing one overwritten “last backup” record.

27. Tips and Best Practices

For New Users

  1. Start small. Set up one library, add a few books, and explore before importing your entire collection.
  2. Use BookDrop for importing rather than manually placing files.
  3. Fetch metadata early. After importing, fetch metadata to fill in titles, authors, covers, and descriptions.
  4. Create shelves to organize your favorites.
  5. Set your reading status so you can track what you’ve read.

For Security

  1. Use strong passwords for all accounts, especially the admin account.
  2. Never expose BookLore directly to the internet without a reverse proxy and authentication.
  3. Keep your OPDS token private.
  4. Review user permissions carefully — only grant deletion rights to trusted users.
  5. Back up regularly — both the database and your book files.

For Performance

  1. Use CBZ over CBR when possible — ZIP extraction is faster than RAR.
  2. Keep image sizes reasonable — extremely high-resolution scans use more memory.
  3. Schedule background tasks during off-hours.
  4. Don’t scan libraries too frequently — once-daily scans are usually sufficient.

For Organization

  1. Be consistent with author names to avoid duplicates.
  2. Use genres and categories — they make filtering and Magic Shelves more useful.
  3. Rate your books — ratings enable great Magic Shelf filters.
  4. Use the Notebook to review all your annotations in one place.
